## What the drills found about themselves

| Observation | Change |
|---|---|
| A worker started inside a subshell kept the drill's output stream open, so the run never seemed to end | The worker is now started with `exec` and every stream on its log |
| Signing in for every probe exhausted the 10-per-15-minutes sign-in budget for the account after a few runs (429) | The drill signs in once and reuses the session from a temporary file. The development Redis counters left by the earlier runs were cleared once by hand |
| The upload-refused check could pass on an empty result | It now requires a finalize status, and checks the upload session and its versions explicitly |
